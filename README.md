# Bash Scripting & Automation Project

This repository contains custom Linux Bash scripts designed to automate routine file management and log analysis tasks on an Amazon Linux EC2 instance.

## 📁 Repository Structure
- `file_manager.sh`: Automated directory setup and file organization script.
- `log_parser.sh`: Log filtering and report generation tool.
- `logs/`: Directory housing generated logs and system reports.

## 🚀 Key Features
- Linux shell scripting best practices.
- Automatic error logging and report outputs.
- Executable shell scripts (`chmod +x`).

## 🛠️ Environment
- **OS**: Amazon Linux 2023 (AWS EC2)
- **Shell**: Bash
